# 2.0.0-beta.2 验证记录

## 本次修正

兼容方威旧类没有 `equipment()` 方法的情况；分别保留 CRM 产品选项和线索名称用词；从原生表单选项补齐分类中不存在的产品映射。

| 检查 | 环境 | 结果 |
|---|---|---|
| PHP 语法 | PHP 8.2.34 / 8.4.26 / 8.5.11 | 每个版本 111 文件通过 |
| 五站旧接口迁移样本 | 同上三个 PHP 版本 | 每站每版本 19 项通过 |
| 原生保存、权限、留言、归因和队列 | 本地 WordPress 7.1.2、SQLite、实际 Bricks 表单源代码 | 每个 PHP 版本 33 项通过 |
| 升级签名及包布局 | 同上三个 PHP 版本，含 ZIP 扩展 | 每个版本 11 项通过 |

五站样本使用脱敏接口，不是实际站点导入。商业 Bricks 源码、站点配置、客户数据、密钥和私有验收环境不发布到此仓库。前端脚本本次未变更，beta.1 的 11 项 DOM 验证继续适用。

公开 CI 运行 PHP 语法、五站接口样本、升级签名及前端 DOM 检查。公开 CI 不包含依赖商业 Bricks 源码的 33 项本地集成检查；没有 ZIP 扩展时只运行升级的 6 项基础守卫。
