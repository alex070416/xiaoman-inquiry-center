# 迁移与在线升级 SOP

## 1. 每站准备

记录原插件版本、启用代码片段、原生表单动作、存储条数、编号前缀、产品类型/分类、小满来源及产品/客户等级映射、客服角色和定时任务。检查待同步、发送中、结果不明及旧版历史队列，避免两套消费者同时运行。

备份数据库、原插件目录、子主题、小满配置和 Cookies 服务到非公开目录；验证备份可恢复。备份包含密钥，禁止上传到公开仓库或公开网站路径。

## 2. 准备统一插件

上传经签名和 SHA-256 验证的固定目录 ZIP。在“设置 → 小满询盘设置”导入原配置，再逐项核对。导入不启用统一处理，不补发历史记录。

重点核对原队列 prefix/cursor/CPT、metadata、编号、小满来源/产品映射、必填规则和旧客服权限。有旧 Bricksforge 队列的站点必须先核对未完成任务，不能将其直接当作原生提交任务重放。

## 3. Cookies

插件内准备唯一服务 `xiaoman-inquiry-attribution`，生成四个声明：

| 类型 | 键 | 保留时间 |
|---|---|---|
| localStorage | xi_first_v1 | 30 天 |
| localStorage | xi_marketing_v1 | 30 天 |
| sessionStorage | xi_visit_v1 | 最后活动后 30 分钟 |
| sessionStorage | xi_session_ad_v1 | 30 分钟 |

在 Real Cookie Banner 中审核服务的用途、所属组、隐私链接和提供者信息，再发布。不能默认取得同意。旧归因服务及旧追踪代码确认停用后，再决定是否停用旧声明。旧 storage 不作为无同意回退来源。

拒绝、撤回、服务缺失或 API 不可用时，不读取保留历史。直接页面 URL 参数仍作为当前询盘上下文。Google Consent Mode / 广告增强型转化为独立配置，迁移前应核对原转化事件、去重和同意信号；不要因更换询盘插件而重复发转化。

## 4. Cloudflare 与 Ads

- 核对 DNS 代理、IP Geolocation、真实来源地址配置及防火墙。
- 检查 `/wp-admin/*`、登录态、`admin-ajax.php`、表单 POST、相关 REST 请求不被缓存；不能凭插件已启用就认为规则已完成。
- 检查 WAF/机器人验证是否拦截原生表单动作，不关闭全站保护。
- Google Ads 给真实落地页传入 utm_source/medium/campaign、campaign_id/adgroup_id/ad_id 等实际参数；PMax keyword 为空可能正常。
- 缓存无需按全部 gclid 建缓存键。访客的来源 URL 不输出进共享缓存 HTML。

## 5. 切换单站

优先使用该站测试副本完成验收。确认页面正常后，停用原询盘主插件及重复的独立必填/后台/同步代码，启用统一处理。动作保留 Save Submission，并将原 Custom 替换为“小满询盘”；有其他 Custom 业务逻辑时先拆分核对，不能直接删除。

统一处理未确认生效前，不清除旧配置或数据。原询盘 URL 可使用后台书签迁移；新固定入口为 `admin.php?page=xiaoman-inquiry-center`。

## 6. 验收

快速、详情、分类、弹窗、翻译页面及移动端各测一条受控询盘；测试记录须明确标识并确认小满测试目的地。核对本地保存一次、小满一次、通知一次、跳转正确；直接跳转/拒绝 Cookies 同样能提交。

测试 PM 空留言拦截、配置 fkxi 前缀拦截、普通广告不误拦、直接 POST 不绕过产品分类规则；对比旧询盘条数、编号、状态及 CRM ID。客服仅能查看/处理询盘，不能配置接口、导出/删除或管理用户。

核对真实定时器运行、401/429 有限重试、网络/5xx 结果不明不自动重发。按广告系列筛选和第 2 页刷新对照耗时及服务器日志。

先单站验证，再对其余四站重复，不将代码包版本一致等同于配置一致。

## 7. 版本发布

修改唯一版本号及发行说明 → 测试 → 本地签名构建 → 核对固定目录与无密钥 → GitHub Release 上传三个文件。Beta 标记为 prerelease；通过五站验收的稳定版本才能作为自动更新来源。

## 8. 回滚

停止统一消费者，恢复原插件和原有效配置，检查队列锁与任务状态后恢复消费者。共享原记录及任务状态可保留在插件回退时；不得在已创建 CRM 线索后盲目恢复旧数据库快照，否则可能丢失成功状态并产生重复线索。

客户数据由网站保存，卸载插件不自动删除。API 端点和来源不能在代码升级时自动切换。
