## 核心已检查行为

- 配置 PM / fkxi 前缀后，空留言被服务器拦截；普通广告不误拦。
- Save Submission 先于小满动作；保存时不进行 CRM HTTP 请求。
- UUID 对应保存行；重复 capture / send 不重复创建线索。
- 并发锁、401 / 429 有限重试、400 拒绝、网络 / 5xx 结果不明不自动重发。
- 结果不明任务经管理员核对后，可以登记已有 CRM ID 或确认不存在后重排。
- 客服角色不能管理设置、用户或删除询盘；回收站暂停任务，恢复后重新排队。
- 不从单独 click ID 编造广告系列；拒绝或过期的 Cookies 历史不被采用。
- 缓存令牌不含访客专属广告必填状态；产品分类规则在服务器端校验。
- 弹窗补充上下文；重复聚焦不反复写属性；原生必填 / minlength 保留。
- 升级清单签名、固定仓库 URL、ZIP 根目录、路径穿越、其他插件更新隔离。

## 正式切换前尚需完成

各站配置导入与历史数据比对、完整 Bricks AJAX 流程、真实快速/详情/分类/弹窗/翻译/移动端页面、Cookies 服务发布及撤回、生产定时器、受控小满测试线索、广告转化去重、Cloudflare Cache Rules / WAF 和 524 时段日志。

GitHub CI 仅运行公开可复现的 PHP 语法、升级清单和前端 DOM 检查。本地的 33 项集成检查含商业 Bricks 源码，不在公开 CI 中运行。
