# beta.6 语言路径修正

状态：修正实际西语感谢页 `/es/thankyou/` 及站点自定义感谢页路径；生产与 Google 对账尚待验收。

- PHP 跳转、浏览器事件门槛、隐私响应标头使用同一组明确配置或 TranslatePress 解析出的路径，避免硬编码英文 slug。
- 自定义路径仅接受本站内一至四级安全路径；拒绝外部 URL、查询字符串、路径穿越。
- 浏览器回归覆盖西语路径、自定义法语路径、无尾斜杠兼容和未配置路径拒绝。
- 本地 WordPress 回归覆盖两类原生保存、唯一编号、语言跳转与双路去重、同意、CRM 重试及独立客户阶段。
- 全部生产测试须保持方威限定、使用获授权的最多 16 条标记记录；不改安行等其余站点。
- `claimed`/`callback` 不等于 Google 报表入账。预发布版本不会通过稳定版自动更新传播到其余站点。

详见 [试点 SOP](CONVERSION-PILOT-SOP.md)。
